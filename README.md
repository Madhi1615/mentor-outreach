# Mentor Outreach Tracker

Private tracker for Madhiyazhagan Ramamoorthy's external mentor and advisor outreach to incubators, B-schools, accelerators and startup missions in India, the Gulf and Southeast Asia.

## Contents

- `index.html`: the interactive tracker (counts, replies, bounces, charts and a searchable table of every organisation)
- `data/Incubation_Outreach_Tracker.xlsx`: master tracker spreadsheet (status, send date, response)
- `data/*_updated.xlsx`: the India, Gulf and Southeast Asia contact databases with Email Status filled in

## How to view

This repository is private, so GitHub Pages is not used. To open the tracker:

1. Download `index.html` (open it on GitHub, then the download button), or clone the repo.
2. Open the file in any browser.
